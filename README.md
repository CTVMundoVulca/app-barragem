# Barragem — Orçamentos

App de orçamentos da **Barragem — Elétrica Geral e Climatização**.

- Catálogo de materiais e mão de obra com preço de venda
- Orçamento com cliente, itens, desconto, condições e validade
- Relatório em **PDF**, impressão A4 e envio pelo **WhatsApp**
- Funciona offline e sincroniza na nuvem (Firebase, projeto AppBarragem)
- Instalável na tela inicial do celular

Endereço (GitHub Pages): https://ctvmundovulca.github.io/app-barragem/
